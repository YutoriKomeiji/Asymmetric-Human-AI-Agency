# Documentation Index

This directory contains the canonical documentation for **Luminalia Core Architecture (LCA)**.

LCA is not a product, framework, or methodology.  
It is a **structural architecture** for designing AI-enabled systems where
responsibility, authority, and agency must remain explicitly human.

This index explains how the documents are structured and how to read them.

---

## How to read this documentation

If this is your first time, read in order:

1. **00-What-is-Safety-LCA.md**  
   Defines what Safety-LCA is and what problem it addresses.

2. **01-Core-Principles.md**  
   Non-negotiable architectural constraints that define the system.

3. **02-Responsibility-Pathways.md**  
   The responsibility pathway model and explicit responsibility points (ERPs).

4. **03-Authority-and-Agency.md**  
   Separation of capability, authority, and agency in system design.

5. **04-Failure-Modes.md**  
   Structural failure patterns (ghost decisions, silent autonomy drift, etc).

6. **05-Design-Implications.md**  
   What changes when these constraints are applied to real systems.

6. **06-Open-Questions.md**  
   Areas intentionally left open for collective exploration.

Each document builds on the previous one.  
They are not independent essays — they are **layers of a single architecture**.
